# BroCode Store Overview for Magento 2

Admin dashboard widget that shows all websites and store views as cards, with live search,
a hide-inactive toggle, logo support, and a REST API for CI pipelines.

Full documentation, screenshots and use cases: **[brocode.at/modules/module-store-overview](https://brocode.at/modules/module-store-overview/)**

## Install

```bash
composer require brocode/module-store-overview
bin/magento module:enable BroCode_StoreOverview
bin/magento setup:upgrade
```
